"# Assigment2" 
Description
This project is a full‑stack web application built using Node.js, Express, MongoDB, and Pug templates.
It allows users to:

Create an account and log in

Search for movies, TV shows, and people using the TMDB API

Apply filters by media type and genre

View detailed information for each item

Add movies or TV shows to a personal list stored in MongoDB

Maintain user sessions using express-session and connect-mongo

Navigate through a clean UI with persistent login and dynamic content rendering

The application is deployed on Vercel using serverless functions for backend routes.
